#### **Note:**



The XLOOKUP function is not available in Excel 2019 or earlier versions.

It was first introduced in Excel for Microsoft 365 and Excel 2021. 



If you are using Excel 2019, Excel 2016, Excel 2013, or Excel 2010, you cannot use XLOOKUP directly. 

Instead, you can:

\- Use traditional lookup functions like VLOOKUP or INDEX/MATCH.

\- Or, use a custom VBA function to mimic XLOOKUP, as shown in the steps above.



This custom VBA approach allows users of older Excel versions to achieve similar lookup functionality without needing to upgrade their software.
